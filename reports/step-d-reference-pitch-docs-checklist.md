### 코드·정적 (확인함)

| 항목 | 결과 |
|------|------|
| ±300 cent가 FREQ 한도 안 | Step A: 262−300≈220.31 ≥ 200 등 — 클램프 미발생(안전망) |

| 항목 | 상태 |
|------|------|
| 표준 440 청취 | 미확인 |
| 저역 262 청취 | 미확인 |
| 중역 330 청취 | 미확인 |
| 앱 재시작 후 선택 유지 | 미확인 (저장 키·로드 코드는 연결됨) |

권장 확인 순서 (Android · wave):

1. 설정 → 표준 → 훈련 → 소리 듣기 → A≈440, 라벨·배지 440  
2. 설정 → 저역 → 새 세션 → A≈262  
3. 설정 → 중역 → 새 세션 → A≈330  
4. 저역 선택 후 앱 완전 종료·재실행 → 설정에 저역 유지  
5. (선택) 세션 저장 후 AsyncStorage/`SessionResult`에 `baseFreq` 존재 확인
