# HarmoniTune (하모니 튠) 사용법

처음 쓰는 분을 위한 짧은 안내입니다.  
이 앱은 **두 소리의 높낮이 차이**를 듣고 구별하는 감각 훈련 앱입니다.

> 본 앱은 의료기기가 아닙니다. 진단·치료·예방 목적으로 사용할 수 없습니다.

---

## 한눈에 보는 흐름

```
홈 → (첫 실행: 볼륨 맞추기) → 훈련 시작 → 소리 듣기(A→B)
   → 높음/낮음 선택 → 반복 → 세션 종료 → 결과 화면 → 통계 확인
```

---

## 1. 시작하기

1. 앱을 실행합니다.
2. 홈 화면에서 **「음고 감각 적응 훈련」** 카드를 누릅니다.
3. **처음이라면 「볼륨 맞추기」 안내가 먼저 나옵니다.** (아래 1-1절)

### 1-1. 첫 실행 — 볼륨 맞추기

처음 훈련에 들어가면 안내 화면이 한 번 나옵니다.

| 단계 | 할 일 |
|------|-------|
| 1 | **이어폰을 착용**하세요 (스피커도 되지만 주변 소음에 영향받습니다) |
| 2 | **「🔊 기준음 들어보기」**를 누르면 같은 음이 4번 반복됩니다.<br>재생되는 동안 기기의 **미디어 볼륨**을 편안한 크기로 맞추세요 |
| 3 | **「훈련 시작」**을 누릅니다 |

> **왜 필요한가요?**  
> 이 훈련은 아주 작은 소리 차이를 듣는 연습입니다.  
> 볼륨이 맞지 않으면 **실력과 무관하게** 어려워집니다.  
> 시력검사 전에 안경을 닦는 것과 같습니다.

이 안내는 **처음 한 번만** 나옵니다.  
다시 보시려면 → 설정 및 정보 → **「볼륨 맞추기 안내 다시 보기」**

## 2. 훈련 화면 구성

| 항목 | 설명 |
|------|------|
| **훈련 / 평가** | 세션 종류 선택 (시작 전에만 변경 가능) |
| **순수 파형 / 사람 목소리** | 소리 종류 선택 (시작 전에만 변경 가능) |
| **음정 차이** | 두 소리의 높이 차이. 작을수록 더 어려운 단계 |
| **기준 Hz** | 소리 A(기준음)의 주파수. 설정에서 고른 값 |
| **연속** | 연속으로 맞힌 횟수 |
| **파형** | 소리 A(파랑·시안) / 소리 B(주황)가 재생 중일 때 움직임 |
| **소리 듣기** | A → 잠깐 쉼 → B 순서로 재생 |
| **다시 듣기** | 아직 답하기 전이라면, **같은 문제**를 그대로 한 번 더 재생 |
| **다음 소리 듣기** | 답한 뒤 다음 문제로 넘어가기 |
| **높음 / 낮음** | B가 A보다 높은지·낮은지 답하기 |

재생 버튼의 문구는 상황에 따라 바뀝니다.

| 상황 | 버튼 문구 | 동작 |
|------|-----------|------|
| 아직 시작 전 | ▶️ 소리 듣기 (A → B) | 첫 문제 재생 |
| 재생 중 | 🔊 소리 감상 중... | 누를 수 없음 |
| 재생 완료, 아직 미답변 | 🔁 다시 듣기 (A → B) | **같은 문제**를 다시 재생 (정답이 바뀌지 않음) |
| 답변 완료 | ▶️ 다음 소리 듣기 (A → B) | **새 문제** 재생 |

## 3. 기본 사용 순서 (추천)

1. **훈련** 탭이 선택된 상태로 둡니다.  
   (처음이면 그대로 두셔도 됩니다.)
2. 소리 모드는 **「순수 파형 (DSP)」** 그대로 두셔도 됩니다.  
   **사람 목소리**는 꼭 누를 필요 없습니다. 다른 느낌으로 듣고 싶을 때만 선택하세요.
3. **「소리 듣기 (A → B)」**를 누릅니다.
4. 첫 번째 소리(A)와 두 번째 소리(B)를 듣습니다.  
   잘 못 들었다면 **「🔁 다시 듣기」**를 눌러 같은 문제를 한 번 더 들을 수 있습니다. (정답은 바뀌지 않습니다)
5. 질문이 나오면 답합니다.  
   > 첫 번째 소리(A) 대비 두 번째 소리(B)의 높낮이는?
6. **높음** 또는 **낮음**을 선택합니다. **한 문제에 한 번만** 답할 수 있습니다.
7. 정답/오답 피드백을 확인한 뒤, **「▶️ 다음 소리 듣기」**로 다음 문제를 진행합니다.

## 4. 난이도(음정 차이)는 어떻게 변하나요?

**음정 차이** = 소리 A와 B의 높이 차이입니다.  
**숫자가 클수록 쉽고, 작을수록 어렵습니다.**

| 항목 | 값 |
|------|-----|
| **시작 음정 차이** | **200** (누구나 들리는 넉넉한 차이) |
| **음정 차이 하한** | 10 (더 이상 안 줄어듦) |
| **음정 차이 상한** | 300 (더 이상 안 커짐) |
| **정답** | **연속 2회** 맞힐 때만 감소 |
| **정답 1회만** | 음정 차이 **유지** |
| **오답** | 바로 증가 |

### 조정 폭은 점점 좁아집니다

한 번에 얼마나 움직이는지는 **고정이 아닙니다.**

| 난이도 방향 전환 횟수 | 조정 폭 |
|------|------|
| 0~1회 | **50씩** (성큼성큼) |
| 2~3회 | **20씩** |
| 4회 이상 | **10씩** (미세 조정) |

> **시력검사와 같습니다.**  
> 큰 글씨부터 시작해서 성큼성큼 작은 줄로 내려가다가,  
> 헷갈리기 시작하는 근처에서 한 줄씩 세밀하게 봅니다.
>
> 수도꼭지로 물 온도 맞추는 것과도 같습니다.  
> 처음엔 크게 돌리고, 적당해지면 조금씩 돌립니다.

예시:

```
문항  음정 차이   결과
 1      200      O   ← 대부분 맞힘
 2      200      O
 3      150      O   (−50)
 4      150      O
 5      100      O   (−50)
 6      100      X   ← 한계 근처 도달
 7      120      O   (+20, 폭이 좁아짐)
 8      120      O
 9      100      O   (−20)
10       90      …   미세 조정 구간
```

**4~6문항이면 자기 수준 근처에 도달합니다.**

### 음정 차이는 왜 이런 숫자인가요? (궁금한 분을 위해)

화면의 **음정 차이**는 피아노 건반 간격으로 이해하면 쉽습니다.

| 비유 | 의미 |
|------|------|
| 반음 한 칸 (도 → 도#) | **100** |
| 시작 음정 차이 **200** | 건반 **두 칸** (도 → 레) |
| 최소 **10** | 아주 미세한 간격까지 조여 가는 단계 |

숫자를 **Hz(헤르츠, 초당 진동 횟수)**로만 올리면, 같은 “+13 Hz”라도 낮은 음과 높은 음에서 **느껴지는 간격이 달라집니다.**  
이 앱은 그래서 **건반 간격처럼 비율로 잰 음정 차이**로 난이도를 맞춥니다. 낮은 음·높은 음에서도 **같은 감각의 간격**을 유지하기 위해서입니다.

시작을 200으로 둔 이유:

- **첫 문제는 맞히면서 시작**하는 편이 감을 잡기 좋습니다.
- 잘하시면 빠르게 내려가므로 시간이 낭비되지 않습니다.
- 사용자는 “높음/낮음”만 고르면 되고, 위 숫자는 **난이도 표시**로 보면 됩니다.

## 5. 점수·통계는 어떻게 계산되나요?

### 세션 안에서 (답할 때마다)

| 항목 | 계산 |
|------|------|
| **시행 수** | 높음/낮음에 답한 횟수 |
| **정답 수** | 맞힌 횟수 |
| **정답률** | 정답 수 ÷ 시행 수 |
| **음정 차이** | 위 4절 규칙으로 조정 |
| **연속** | 연속으로 맞힌 횟수 (틀리면 0) |

매 답변마다 화면의 음정 차이·연속·정답률은 바로 바뀝니다.  
다만 **저장하기 전에는 통계 화면에 남지 않습니다.**

### 대표 점수 — 변별 역치

이 앱의 **가장 중요한 숫자**입니다. 구별할 수 있는 **가장 작은 음정 차이**를 뜻하며,
**숫자가 작을수록 정밀하게 듣고 있다**는 의미입니다.

> **시력검사와 같은 방식으로 잽니다.**  
> 검사에서 한 번 운 좋게 읽어낸 **가장 작은 글씨**를 시력으로 적지는 않습니다.  
> 큰 줄과 작은 줄을 오르내리며 “겨우 보이는 경계”를 여러 번 찾고, **그 지점들을 평균**냅니다.

이 앱도 똑같이 합니다. 난이도가 **내려가다 올라가거나, 올라가다 내려간 지점**(＝난이도 방향 전환)을
모아서 평균을 냅니다.

```
음정 차이
 200 ┐ 맞힘
 150 ┤ 맞힘
 100 ┤── 틀림 → 방향 전환 ①  (100 기록)
 150 ┤── 맞힘 → 방향 전환 ②  (150 기록)
 100 ┤
  80 ┤── 틀림 → 방향 전환 ③  ( 80 기록)
 100 ┘── 맞힘 → 방향 전환 ④  (100 기록)

처음 2개는 아직 내려오는 중이라 제외 → [80, 100] → 역치 = 90
```

**방향 전환이 4회 이상**이어야 역치가 나옵니다. 그보다 짧으면 `-`로 표시됩니다.  
훈련 화면 아래에 `난이도 방향 전환 2/4` 처럼 진행 상황이 보입니다.

> **왜 “가장 작은 값”을 안 쓰나요?**  
> 이 게임은 높음/낮음 둘 중 하나라 **찍어도 절반은 맞습니다.**  
> 운 좋게 두 번 연속 찍어 맞히면 실력과 무관하게 최솟값이 뚝 떨어집니다.  
> 여러 지점의 평균이 훨씬 안정적입니다.

### 통계에 남기려면 (저장)

1. 시행을 **3회 이상** 해야 「세션 종료 및 저장」이 나타납니다.  
   (화면 아래 `0/3` → `1/3` → `2/3` 진행 표시)
2. 3회는 **기록을 남기기 위한 최소 횟수**입니다.  
   점수 공식 자체가 “3회부터 계산”되는 것은 아닙니다.
3. **3회 미만**으로 뒤로 나가면 → 그 세션은 **저장되지 않음** (통계 미반영).
4. **3회 이상** 하고 저장하면 → 그 시점까지의 시행·정답·역치가 통계에 반영됩니다.
5. 3회를 넘겨 **더 많이 풀면**  
   - 총 시행·정답 수가 늘고  
   - **전체 정답률**(전체 정답 ÷ 전체 시행)에 반영되며  
   - **난이도 방향 전환이 4회 이상 쌓여야 변별 역치가 산출됩니다.**  
   짧게 끝내면 역치 없이 시행 기록만 남습니다.

### 통계 화면 요약 지표

| 지표 | 의미 |
|------|------|
| **변별 역치 (최고)** | 지금까지 기록 중 **가장 낮은(＝가장 좋은)** 역치 |
| **최근 역치** | 가장 최근 세션에서 나온 역치 |
| **누적 정답률** | 저장된 전체 정답 수 ÷ 전체 시행 수 |
| **평균 반응 시간** | 저장된 시행들의 평균 응답 시간. **소리 재생이 끝난 시점부터** 답을 고를 때까지 걸린 시간입니다 (소리 듣는 2.5초는 포함되지 않습니다) |
| **총 세션 · 시행** | 그리드 아래 요약 줄에 표시 |

성장을 보시려면 **최고 역치와 최근 역치를 함께** 보세요.  
둘 다 내려가고 있다면 잘 되고 있는 것입니다.

## 6. 훈련 vs 평가

두 모드는 **실제로 다르게 동작합니다.**

| 항목 | 🏋️ 훈련 | 📋 평가 |
|------|---------|---------|
| **언제** | 평소 연습할 때 (기본값) | 현재 수준을 점검할 때 |
| **문제마다 정답 공개** | 공개 | **숨김** — "답변이 기록되었습니다"만 표시 |
| **결과** | 그때그때 확인 | **끝나고 한 번에** |
| **종료** | 원할 때 직접 종료 | **자동 종료** (방향 전환 8회 또는 30문항) |

> **왜 평가는 정답을 안 알려주나요?**  
> 시험 중에 문제마다 정답을 알려주면, 뒷 문제는 앞에서 배운 걸로 풉니다.  
> 그러면 “원래 실력”이 아니라 “배우면서 푼 실력”을 재게 됩니다.  
> 그래서 시험은 **끝나고 채점**합니다.
>
> **왜 자동으로 끝나나요?**  
> 시험은 문항 수가 정해져 있어야 점수를 비교할 수 있습니다.  
> 어떤 날은 5문제, 어떤 날은 50문제를 풀면 두 결과를 나란히 놓을 수 없습니다.

세션이 이미 시작된 뒤에는 모드를 바꿀 수 없습니다.  
바꾸려면 **세션 종료** 후 다시 고르세요.

## 6-1. 소리를 놓쳤을 때

훈련 중에 **전화가 오거나 앱을 잠깐 나갔다 오면**, 그 문제는 자동으로 **버려집니다.**

```
소리를 놓쳐 이번 문제는 기록하지 않았습니다.
새 문제로 다시 시작해 주세요.
```

이 안내가 뜨면 재생 버튼을 눌러 **새 문제**로 계속하시면 됩니다.  
못 들은 문제에 찍은 답이 기록에 남지 않도록 하기 위한 장치입니다.

> 같은 문제를 다시 주지 않는 이유: 소리를 **일부만** 들었을 수 있습니다.  
> A는 들었고 B만 놓쳤다면, 같은 문제를 다시 줄 때 A의 기억이 힌트가 됩니다.

## 7. 세션 끝내기

1. 시행을 **3회 이상** 하면 **「세션 종료 및 저장」** 버튼이 나타납니다.  
   (3회 미만에는 아래 진행 바 `n/3`만 보입니다.)
2. 누르면 결과가 저장되고 **결과 화면**으로 넘어갑니다. (아래 7-1절)
3. 평가 모드는 조건을 채우면 **버튼을 누르지 않아도 자동으로** 결과 화면으로 갑니다.

> 저장에 실패하면 **「저장 실패」 안내가 뜹니다.**  
> 이 안내가 없었다면 정상적으로 저장된 것입니다.

### 7-1. 결과 화면

세션이 끝나면 나오는 화면입니다.

| 항목 | 설명 |
|------|------|
| **변별 역치** | 가장 크게 표시되는 이번 세션의 대표 점수 |
| **지난번보다 n 좋아졌습니다** | 직전 기록과 비교. 역치가 둘 다 있어야 나옵니다 |
| 시행 · 정답률 · 평균 반응(ms) | 세부 지표 |
| **난이도 궤적** | 문항마다 음정 차이가 어떻게 움직였는지 (`200 → 150 → …`) |
| 방향 전환 지점 | 역치 계산에 쓰인 값들 |

아래 버튼으로 **「한 세션 더」 / 「통계 보기」 / 「홈으로」** 중 고를 수 있습니다.

> 역치가 안 나온 세션은 `—`로 표시되고,  
> **방향 전환이 몇 번 있었는지**를 함께 보여줍니다.

아래로 당겨서 새로고침할 수 있습니다.

### 8-1. 역치 추이 그래프

세션이 **2회 이상** 쌓이면 변화를 선그래프로 그려 드립니다.

> **선이 위로 올라가면 좋아지는 중입니다.**  
> 역치는 숫자가 작을수록 좋기 때문에, 그래프는 **위쪽이 낮은 값**이 되도록 뒤집어 그렸습니다.  
> 그냥 그리면 실력이 늘수록 선이 내려가서 직관과 반대로 보이기 때문입니다.

- 오른쪽 끝 **주황색 점**이 가장 최근 기록입니다.
- 오른쪽 위에 `↓ 12 개선` 처럼 첫 기록 대비 변화가 표시됩니다.

앱 안내·환경 관련 정보를 확인하는 화면입니다.  
처음 훈련만 하려면 열어보지 않아도 됩니다. (기본 기준음은 **440 Hz**)

### 진동 피드백

정답·오답일 때 짧게 **진동**으로도 알려 줍니다. 기본은 **켜짐**입니다.

- 소리에 집중하기 어려운 환경에서 특히 도움이 됩니다.
- 진동이 거슬리면 여기서 끄시면 됩니다.
- **평가 모드에서는 정답/오답을 구분하지 않는 진동**만 옵니다.
  (진동으로 정답을 알려주면 정답을 숨긴 의미가 없어지기 때문입니다)

### 기준 음고 선택

설정에서 **소리 A(기준음)** 주파수를 고를 수 있습니다. 고른 값은 앱을 다시 켜도 유지되며, 다음 훈련 세션의 기준음으로 쓰입니다.

| 선택 | 주파수 | 설명 |
|------|--------|------|
| **표준 (A4)** | 440 Hz | 기본값. 일반 훈련 |
| **중역** | 330 Hz | 한 단계 낮은 체감 |
| **저역** | 262 Hz | 더 낮은 기준음 |

- **고역(440 Hz 초과) 프리셋은 없습니다.** 고주파 자극을 피하기 위한 선택입니다.
- 처음에는 **표준(440)** 그대로 두셔도 됩니다.
- 바꾸는 방법: 홈 → 설정 및 정보 → 원하는 기준 음고 행을 탭 → 훈련 화면에서 소리 듣기.
- 이미 훈련 세션이 진행 중이면, 설정을 바꿔도 **그 세션이 끝난 뒤** 새 세션부터 반영됩니다.
- 본 훈련은 **순수 파형** 모드로 먼저 듣는 것을 권장합니다. (사람 목소리 모드는 후속 조정 대상일 수 있음)

## 자주 하는 질문

### Q. 기준 음고를 꼭 바꿔야 하나요?
아니요. 기본 **표준 440 Hz**로도 충분합니다. 더 낮은 기준으로 듣고 싶을 때만 설정에서 중역·저역을 고르세요.

### Q. 고음(높은 Hz) 기준음은 없나요?
없습니다. 표준·중역·저역만 제공하며, 440 Hz를 넘는 고역 프리셋은 두지 않습니다.

### Q. 사람 목소리 버튼을 꼭 눌러야 하나요?
아니요. 기본인 **순수 파형**만으로 충분합니다.

### Q. 두 소리 차이가 거의 안 나요.
처음 몇 문항은 **음정 차이 200**이라 꽤 뚜렷하게 들려야 정상입니다.  
그래도 잘 모르겠다면 **미디어 볼륨**과 **이어폰 연결**을 먼저 확인해 보세요.  
문항이 진행되면 차이가 점점 좁아지므로, 뒤로 갈수록 어려워지는 것은 정상입니다.

### Q. 음정 차이 숫자는 뭐고, 왜 Hz로 안 쓰나요?
피아노로 치면 **반음 한 칸이 100**, 시작 **200은 건반 두 칸(도 → 레)**입니다.  
Hz(절대 주파수)로만 간격을 키우면 저음·고음에서 체감이 달라져서, 앱은 **건반 간격처럼 비율로 잰 음정 차이**로 난이도를 맞춥니다.  
자세한 설명은 **4절** 「음정 차이는 왜 이런 숫자인가요?」를 보세요.

### Q. 정답마다 음정 차이가 줄어드나요?
아니요. **연속 2회 정답일 때만** 줄어듭니다. 오답은 **바로** 늘어납니다.  
줄어드는 폭은 고정이 아니라 **50 → 20 → 10**으로 점점 좁아집니다. (4절 참고)

### Q. 「변별 역치」가 계속 `-`로 나와요.
**난이도 방향 전환이 4회 이상** 쌓여야 산출됩니다.  
훈련 화면 아래 `난이도 방향 전환 2/4` 표시로 진행 상황을 볼 수 있습니다.  
너무 짧게 끝내면 역치 없이 시행 기록만 남습니다. 조금 더 풀어 보세요.

### Q. 「평가」를 눌렀는데 정답을 안 알려줘요.
정상입니다. 평가 모드는 **일부러** 정답을 숨깁니다.  
도중에 요령을 배우면 “현재 실력”이 아니라 “배운 뒤 실력”을 재게 되기 때문입니다.  
결과는 평가가 끝난 뒤 한 번에 나옵니다. (6절 참고)

### Q. 평가가 저절로 끝났어요.
정상입니다. 평가는 **난이도 방향 전환 8회** 또는 **30문항**에서 자동 종료됩니다.  
매번 같은 조건에서 재야 결과를 비교할 수 있기 때문입니다.

### Q. 「소리를 놓쳐 이번 문제는 기록하지 않았습니다」가 떴어요.
전화가 오거나 앱을 잠깐 나갔다 오면 그 문제는 버려집니다.  
못 들은 문제에 찍은 답이 기록에 남지 않도록 하는 장치입니다.  
재생 버튼을 눌러 **새 문제**로 계속하세요. (6-1절 참고)

### Q. 소리는 안 들리는데 파형만 움직여요.
기기/에뮬레이터의 **미디어 볼륨**을 확인해 보세요.  
그래도 안 들리면 앱을 다시 실행한 뒤, 재생 버튼을 한 번 더 눌러 보세요.

### Q. 「높음/낮음」 버튼이 안 눌려요.
다음 세 경우에 비활성화됩니다.

- 소리가 재생 중일 때
- 아직 첫 재생 전(`소리 듣기`를 누르기 전)
- **이미 그 문제에 답한 뒤** (한 문제당 한 번만 답할 수 있습니다)

A→B 재생이 끝난 뒤에 선택하시고, 답한 뒤에는 **「다음 소리 듣기」**로 넘어가세요.

### Q. 「다시 듣기」를 누르면 문제가 바뀌나요?
아니요. **같은 문제를 그대로 다시 들려줍니다.** 정답(B가 높은지 낮은지)은 바뀌지 않습니다.  
답한 뒤에 누르는 **「다음 소리 듣기」**부터가 새 문제입니다.

### Q. 의료용으로 써도 되나요?
아니요. 웰니스·감각 훈련용 콘텐츠이며 의료기기가 아닙니다.
