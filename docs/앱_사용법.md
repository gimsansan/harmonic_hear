# HarmoniTune (하모니 튠) 사용법

처음 쓰는 분을 위한 짧은 안내입니다.  
이 앱은 **두 소리의 높낮이 차이**를 듣고 구별하는 감각 훈련 앱입니다.

> 본 앱은 의료기기가 아닙니다. 진단·치료·예방 목적으로 사용할 수 없습니다.

---

## 한눈에 보는 흐름

```
홈 → 훈련 시작 → 소리 듣기(A→B) → 높음/낮음 선택 → 반복 → 세션 저장 → 통계 확인
```

---

## 1. 시작하기

1. 앱을 실행합니다.
2. 홈 화면에서 **「음고 감각 적응 훈련」** 카드를 누릅니다.
3. 이어폰 또는 스피커 볼륨을 미리 맞춰 둡니다.  
   (소리가 너무 작으면 차이를 느끼기 어렵습니다.)

---

## 2. 훈련 화면 구성

| 항목 | 설명 |
|------|------|
| **훈련 / 평가** | 세션 종류 선택 (시작 전에만 변경 가능) |
| **순수 파형 / 사람 목소리** | 소리 종류 선택 (시작 전에만 변경 가능) |
| **음정 차이** | 두 소리의 높이 차이. 작을수록 더 어려운 단계 |
| **연속** | 연속으로 맞힌 횟수 |
| **파형** | 소리 A(파랑·시안) / 소리 B(주황)가 재생 중일 때 움직임 |
| **소리 듣기** | A → 잠깐 쉼 → B 순서로 재생 |
| **높음 / 낮음** | B가 A보다 높은지·낮은지 답하기 |

---

## 3. 기본 사용 순서 (추천)

1. **훈련** 탭이 선택된 상태로 둡니다.  
   (처음이면 그대로 두셔도 됩니다.)
2. 소리 모드는 **「순수 파형 (DSP)」** 그대로 두셔도 됩니다.  
   **사람 목소리**는 꼭 누를 필요 없습니다. 다른 느낌으로 듣고 싶을 때만 선택하세요.
3. **「소리 듣기 (A → B)」**를 누릅니다.
4. 첫 번째 소리(A)와 두 번째 소리(B)를 듣습니다.
5. 질문이 나오면 답합니다.  
   > 첫 번째 소리(A) 대비 두 번째 소리(B)의 높낮이는?
6. **높음** 또는 **낮음**을 선택합니다.
7. 정답/오답 피드백을 확인한 뒤, 다시 **소리 듣기**로 다음 문제를 진행합니다.

---

## 4. 난이도(음정 차이)는 어떻게 변하나요?

**음정 차이** = 소리 A와 B의 높이 차이입니다.  
**숫자가 클수록 쉽고, 작을수록 어렵습니다.**

| 항목 | 값 |
|------|-----|
| **시작 음정 차이** | 50 |
| **최소 음정 차이** | 10 (더 이상 안 줄어듦) |
| **최대 음정 차이** | 150 (더 이상 안 커짐) |
| **정답** | **연속 2회** 맞힐 때만 **−10** |
| **정답 1회만** | 음정 차이 **유지** (연속 카운트만 1) |
| **오답** | 바로 **+10**, 연속 카운트 0으로 리셋 |

예시 (시작 50):

```
정답 → 50 유지 (연속 1)
또 정답 → 40 (−10, 연속 2회라 감소)
오답 → 50 (+10, 연속 리셋)
```

처음 음정 차이 50은 반음의 절반 정도라, 차이가 **크게** 들리지 않는 것이 정상입니다.

### 음정 차이는 왜 이런 숫자인가요? (궁금한 분을 위해)

화면의 **음정 차이**는 피아노 건반 간격으로 이해하면 쉽습니다.

| 비유 | 의미 |
|------|------|
| 반음 한 칸 (도 → 도#) | **100** |
| 시작 음정 차이 **50** | 그 칸의 **절반** (건반과 건반 사이 중간쯤) |
| 최소 **10** | 아주 미세한 간격까지 조여 가는 단계 |

숫자를 **Hz(헤르츠, 초당 진동 횟수)**로만 올리면, 같은 “+13 Hz”라도 낮은 음과 높은 음에서 **느껴지는 간격이 달라집니다.**  
이 앱은 그래서 **건반 간격처럼 비율로 잰 음정 차이**로 난이도를 맞춥니다. 낮은 음·높은 음에서도 “반음의 절반” 같은 **같은 감각의 간격**을 유지하기 위해서입니다.

시작을 50으로 둔 이유도 비슷합니다.

- 처음부터 너무 티 나게 쉽게(예: 아주 큰 간격) 두지 않고, **세밀한 듣기**로 들어가게 합니다.
- 어려우면 오답 시 간격이 커져 조금 쉬워지고, 잘하면 연속 정답으로 더 조여집니다.
- 사용자는 “높음/낮음”만 고르면 되고, 위 숫자는 **난이도 표시**로 보면 됩니다.

## 5. 점수·통계는 어떻게 계산되나요?

### 세션 안에서 (답할 때마다)

| 항목 | 계산 |
|------|------|
| **시행 수** | 높음/낮음에 답한 횟수 |
| **정답 수** | 맞힌 횟수 |
| **정답률** | 정답 수 ÷ 시행 수 |
| **음정 차이** | 위 4절 규칙으로 ±10 조정 |
| **최소 음정 차이** | 그 세션에서 도달한 **가장 작은** 음정 차이 (더 어려운 단계) |

매 답변마다 화면의 음정 차이·연속·정답률은 바로 바뀝니다.  
다만 **저장하기 전에는 통계 화면에 남지 않습니다.**

### 통계에 남기려면 (저장)

1. 시행을 **3회 이상** 해야 「세션 종료 및 저장」이 나타납니다.  
   (화면 아래 `0/3` → `1/3` → `2/3` 진행 표시)
2. 3회는 **기록을 남기기 위한 최소 횟수**입니다.  
   점수 공식 자체가 “3회부터 계산”되는 것은 아닙니다.
3. **3회 미만**으로 뒤로 나가면 → 그 세션은 **저장되지 않음** (통계 미반영).
4. **3회 이상** 하고 저장하면 → 그 시점까지의 시행·정답·최소 음정 차이가 통계에 반영됩니다.
5. 3회를 넘겨 **더 많이 풀고 정답을 많이 맞히면**  
   - 총 시행·정답 수가 늘고  
   - **전체 정답률**(전체 정답 ÷ 전체 시행)에 유리하게 반영되며  
   - 연속 정답으로 음정 차이가 더 줄어들면 **최소 음정 차이(최고 난이도) 기록**도 좋아집니다.  
   (오답이 많으면 정답률에는 불리합니다.)

### 통계 화면 요약 지표

| 지표 | 의미 |
|------|------|
| **총 세션 수** | 저장한 세션 개수 |
| **총 시행 수** | 저장된 모든 세션의 시행 합 |
| **전체 정답률** | 저장된 전체 정답 수 ÷ 전체 시행 수 |
| **최소 음정 차이** | 지금까지 저장 기록 중 **가장 작은** 음정 차이 (= 가장 어려운 단계까지 간 기록) |
| **평균 반응 시간** | 저장된 시행들의 평균 응답 시간 |

## 6. 훈련 vs 평가

| 모드 | 언제 쓰나요? |
|------|----------------|
| **훈련** | 평소 연습할 때 (기본값) |
| **평가** | 현재 감각 수준을 점검하고 싶을 때 |

세션이 이미 시작된 뒤에는 모드를 바꿀 수 없습니다.  
바꾸려면 **세션 종료** 후 다시 고르세요.

---

## 7. 세션 끝내기

1. 시행을 **3회 이상** 하면 **「세션 종료 및 저장」** 버튼이 나타납니다.  
   (3회 미만에는 아래 진행 바 `n/3`만 보입니다.)
2. 누르면 결과가 저장되고, 시행 수·정답률·최소 음정 차이 요약이 표시됩니다.
3. 홈으로 돌아가 **「훈련 통계」**에서 기록을 볼 수 있습니다.

---

## 8. 통계 화면

홈 → **훈련 통계**

- 총 세션 수, 총 시행 수, 전체 정답률
- 지금까지 달성한 **가장 작은(가장 어려운) 음정 차이**
- 최근 세션 목록

자세한 계산은 **5절**을 참고하세요.

## 자주 하는 질문

### Q. 사람 목소리 버튼을 꼭 눌러야 하나요?
아니요. 기본인 **순수 파형**만으로 충분합니다.

### Q. 두 소리 차이가 거의 안 나요.
정상입니다. 처음 음정 차이(50)가 크지 않아서, 세밀한 듣기를 연습하는 구조입니다.  
오답이 나오면 음정 차이가 +10 되어 구분이 조금 쉬워집니다.

### Q. 음정 차이 숫자는 뭐고, 왜 Hz로 안 쓰나요?
피아노로 치면 **반음 한 칸이 100**, 시작 **50은 그 절반**입니다.  
Hz(절대 주파수)로만 간격을 키우면 저음·고음에서 체감이 달라져서, 앱은 **건반 간격처럼 비율로 잰 음정 차이**로 난이도를 맞춥니다.  
자세한 설명은 **4절** 「음정 차이는 왜 이런 숫자인가요?」를 보세요.

### Q. 정답마다 음정 차이가 −10인가요?
아니요. **연속 2회 정답일 때만 −10**입니다. 오답은 **바로 +10**입니다.

### Q. 소리는 안 들리는데 파형만 움직여요.
기기/에뮬레이터의 **미디어 볼륨**을 확인해 보세요.  
그래도 안 들리면 앱을 다시 실행한 뒤, 재생 버튼을 한 번 더 눌러 보세요.

### Q. 「높음/낮음」 버튼이 안 눌려요.
소리가 재생 중이거나, 아직 첫 재생 전(`소리 듣기`를 누르기 전)이면 비활성화됩니다.  
A→B 재생이 끝난 뒤에 선택하세요.

### Q. 의료용으로 써도 되나요?
아니요. 웰니스·감각 훈련용 콘텐츠이며 의료기기가 아닙니다.
