## 1. 순수 파형 / 사람 목소리 토글

**세션이 시작된 뒤부터 잠김.**

- 잠기는 조건: `isSessionActive === true`
- 세션이 켜지는 시점: **「소리 듣기」를 처음 누른 순간** (그때 `handleStartSession` 실행)
- 잠기면: 활성 탭에 `🔒` 표시 + 안내 문구  
  `"세션 중에는 소리 종류를 바꿀 수 없습니다. 바꾸려면 세션을 끝내세요."`
- 다시 열리는 시점: **세션 종료** (`isSessionActive`가 `false`로 돌아갈 때)

훈련/평가 탭도 **같은 조건**으로 잠깁니다. 세션 중엔 둘 다 못 바꿉니다.

---

## 2. 뒤로가기 / 나가기

여기는 **두 개가 다릅니다.**

| 동작 | 언제 되나 | 비고 |
|---|---|---|
| **← 뒤로** | **항상 가능** (세션 중이어도) | `router.back()`만 호출. 막지 않음. 확인창도 없음. 중도 이탈 시 **저장 안 됨** |
| **세션 종료 및 저장** | 세션 활성 + **문항 3회 이상**일 때만 | `totalTrials < 3`이면 버튼 자체가 없고 `0/3` 진행 바만 보임 |

그래서 “나가기가 안 될 때”는 대개 이 경우예요:

- 소리 듣기를 눌러 세션은 시작됐는데
- 아직 **답이 3번 미만**이라
- **「세션 종료 및 저장」이 안 나오고** 진행 바만 보이는 상태

이때 나갈 수 있는 건 **← 뒤로**뿐이고, 그건 저장 없이 나갑니다.

평가 모드는 별도로, 조건 충족 시 **자동 종료**됩니다 (방향 전환 8회 또는 최대 30문항).

## 한 줄 정리

- **모드 토글 안 됨** → 세션 시작 후(첫 재생 후)부터, 세션 끝날 때까지  
- **세션 종료 버튼 안 보임** → 문항 3회 미만  
- **← 뒤로** → 코드상으로는 **막히지 않음** (다만 저장 없이 이탈)

원하시면 다음으로 “3회 미만에도 강제 종료(저장/폐기 선택)”가 UX상 맞는지 짚어드릴게요.
