# 하모니튠 코드 한 줄씩 해설 (초보자용)

> 각 파일을 **구간(코드 덩어리) 단위로 잘게 쪼개서** 한 줄씩 풀어 설명합니다.
> 코딩을 처음 보는 분도 따라올 수 있게, "이 줄이 왜 있는지"에 집중했어요.
> 스타일(색·여백)만 정의하는 `StyleSheet` 부분은 핵심이 아니라 간단히만 언급합니다.

## 읽는 순서 추천
소리 → 규칙 → 화면 순서가 이해하기 쉬워요.
1. `src/constants/theme.ts` (모든 규칙 수첩)
2. `src/audio/pitchUtils.ts` → `AudioEngine.ts` (소리)
3. `src/training/StaircaseEngine.ts` → `SessionManager.ts` → `trainingFlow.ts` (훈련 두뇌)
4. `src/storage/*`, `src/utils/haptics.ts` (저장·진동)
5. `src/components/*` (화면 부품)
6. `app/*` (화면)

# 1. `src/constants/theme.ts` — 모든 규칙이 적힌 수첩

이 파일은 함수가 없어요. **숫자와 설정값만 모아둔 곳**입니다.

```ts
export const COLORS = {
  background: '#12131C',  // 어두운 남색 배경
  primary: '#00E5FF',     // 소리 A(시안색)
  secondary: '#FF6D00',   // 소리 B(주황색)
  ...
} as const;
```
- `export` : "다른 파일에서 가져다 써도 된다"는 뜻. (수첩을 공유)
- `as const` : "이 값들은 절대 안 바뀐다"고 못 박는 표시. 실수로 바꾸는 걸 막아줘요.

```ts
export const AUDIO = {
  BASE_FREQ: 440,       // 기준음 (피아노 '라' 음)
  FREQ_MIN_HZ: 200,     // 이보다 낮은 소리는 안 냄
  FREQ_MAX_HZ: 2000,    // 이보다 높은 소리도 안 냄
  TONE_DURATION: 1.0,   // 소리 하나를 1초 재생
  GAP_DURATION: 0.5,    // A와 B 사이 0.5초 쉼
};
```
- 소리에 관한 모든 숫자가 여기 있어요. 여기 `TONE_DURATION`만 바꿔도 앱 전체 소리 길이가 바뀝니다.

```ts
export const STAIRCASE = {
  INITIAL_CENTS: 200,      // 처음엔 차이 200(쉬움)에서 시작
  MIN_CENTS: 10,           // 아무리 어려워도 최소 10까지만
  MAX_CENTS: 300,          // 아무리 쉬워도 최대 300까지만
  STREAK_THRESHOLD: 2,     // 2번 연속 맞히면 어려워짐
  STEP_SCHEDULE: [         // 반전이 쌓일수록 조정 폭을 줄임
    { fromReversal: 0, step: 50 },   // 초반엔 크게(50)
    { fromReversal: 2, step: 20 },   // 중반엔 중간(20)
    { fromReversal: 4, step: 10 },   // 후반엔 미세(10)
  ],
  THRESHOLD_MIN_REVERSALS: 4,  // 방향 전환 4번은 있어야 점수 산출
};
```
- **cent(센트)** = 음 높이 차이를 재는 단위. 100 cent = 반음. 숫자가 작을수록 두 소리가 비슷 = 어려움.
- `STEP_SCHEDULE` : "처음엔 성큼성큼, 나중엔 살금살금" 움직이라는 표.

```ts
export const ASSESSMENT = {
  TARGET_REVERSALS: 8,  // 방향 전환 8번이면 평가 자동 종료
  MAX_TRIALS: 30,       // 아니면 30문제에서 강제 종료
};
```
- **평가 모드**는 사용자가 아무 때나 멈추면 매번 조건이 달라져 비교가 안 되므로, **정해진 조건에서 자동으로 끝나게** 하는 값들.

# 2. `src/audio/pitchUtils.ts` — 음 높이 계산기

소리를 만들기 전, "몇 Hz로 틀지"를 계산하는 도우미 함수 모음.

```ts
export function centsToFreq(baseHz: number, cents: number): number {
  return baseHz * Math.pow(2, cents / 1200);
}
```
- **"기준음에서 cents만큼 높은/낮은 음은 몇 Hz인가?"** 를 구함.
- 공식: `f = 기준 × 2^(cents/1200)`. 1200 cent = 한 옥타브(주파수 2배)라서 1200으로 나눠요.
- 예: `centsToFreq(440, 100)` → 약 466Hz (반음 위).

```ts
export function freqToCents(baseHz: number, targetHz: number): number {
  return 1200 * Math.log2(targetHz / baseHz);
}
```
- 위의 **반대 계산**. "두 Hz 차이는 몇 cent인가?"

```ts
export function clampFreq(hz, minHz = 200, maxHz = 2000) {
  if (hz < minHz) return { clamped: minHz, wasOverLimit: true };
  if (hz > maxHz) return { clamped: maxHz, wasOverLimit: true };
  return { clamped: hz, wasOverLimit: false };
}
```
- **"안전 울타리"** 함수. 계산된 주파수가 너무 낮거나 높으면 허용 범위 안으로 잘라줌.
- `wasOverLimit` : 잘렸는지 여부를 같이 알려줘요 (나중에 몇 번 잘렸는지 세기 위해).

# 3. `src/audio/AudioEngine.ts` — 소리를 만드는 신디사이저

```ts
export class AudioEngine {
  private ctx: AudioContext | null = null;
```
- `class` = 소리 관련 기능을 한 상자에 묶은 것.
- `ctx` = 오디오를 다루는 "작업 공간". 처음엔 아직 없어서 `null`.
- `private` = 이 상자 안에서만 쓰는 값 (밖에서 못 건드림).

```ts
  init(): void {
    if (!this.ctx) {
      this.ctx = new AudioContext();
    }
  }
```
- 오디오 작업 공간을 **켠다**. 화면이 열릴 때 호출.
- `if (!this.ctx)` : 이미 켜져 있으면 또 안 켜게 방지.

```ts
  dispose(): void {
    if (this.ctx) {
      this.ctx.close();
      this.ctx = null;
    }
  }
```
- 오디오 작업 공간을 **끄고 치운다**. 화면을 나갈 때 호출. (메모리 낭비 방지)

```ts
  async ensureRunning(): Promise<boolean> {
    if (!this.ctx) this.init();
    ...
    if (this.ctx.state !== 'running') {
      await this.ctx.resume();
    }
    return true;
  }
```
- 스마트폰은 사용자가 버튼을 누르기 전엔 소리 재생을 막아둬요(자동재생 방지).
- 그래서 재생 직전에 이 함수로 **"오디오야 깨어나라"** 하고 깨웁니다.
- `async / await` = "시간이 걸리는 일을 기다렸다가 다음 줄 실행". (오디오 깨어나는 데 잠깐 걸림)

```ts
  async playSequence(tones, mode): Promise<boolean> {
    const ready = await this.ensureRunning();
    if (!ready || !this.ctx) return false;

    const ctx = this.ctx;
    const base = ctx.currentTime;   // ★ 시간의 기준점을 한 번만 읽는다

    for (const tone of tones) {
      const startTime = base + tone.offset;   // 기준점 + 상대시각
      if (mode === 'wave') this.playSineTone(ctx, tone.freq, startTime, tone.duration);
      else this.playVoiceTone(ctx, tone.freq, startTime, tone.duration);
    }
    return true;
  }
```
- **이 앱에서 가장 중요한 함수예요.**
- `const base = ctx.currentTime` : 시간 원점을 **딱 한 번** 찍어둠.
- A와 B를 각각 `base + 0초`, `base + 1.5초`처럼 **미리 예약**해요.
- 왜? 소리마다 따로 "지금 재생!"을 하면, 그 사이 폰이 버벅인 시간만큼 A→B 간격이 흔들려요.
  간격이 흔들리면 사용자가 **높낮이가 아니라 "타이밍"으로 정답을 눈치**챌 수 있어서, 측정이 망가집니다.
- 그래서 한 기준점에 몰아서 예약 → 간격이 항상 정확.

```ts
  private playSineTone(ctx, freq, startTime, duration): void {
    const osc = ctx.createOscillator();  // 소리를 만드는 발진기
    const gain = ctx.createGain();       // 볼륨 조절기

    osc.type = 'sine';                   // 맑은 '삐~' 파형
    osc.frequency.setValueAtTime(freq, startTime);  // 이 주파수로 설정

    // 볼륨을 서서히 키웠다(Attack) 유지(Sustain)했다 줄임(Release)
    gain.gain.setValueAtTime(0.001, startTime);
    gain.gain.exponentialRampToValueAtTime(peak, attackEnd);
    gain.gain.setValueAtTime(peak, releaseStart);
    gain.gain.exponentialRampToValueAtTime(0.001, end);

    osc.connect(gain);            // 발진기 → 볼륨조절기
    gain.connect(ctx.destination); // 볼륨조절기 → 스피커
    osc.start(startTime);
    osc.stop(end);
  }
```
- **순수 파형("삐~") 소리**를 만드는 부분.
- 볼륨을 갑자기 켜면 "딱!" 하는 잡음이 나요. 그래서 **서서히 켜고 서서히 끄는**(엔벨로프) 처리를 합니다.
- `connect` = 장비를 케이블로 잇는 것과 같아요. 발진기 → 볼륨 → 스피커 순서로 연결.

```ts
  private playVoiceTone(...) {
    osc.type = 'sawtooth';        // 톱니 파형(거친 소리)
    const filter1 = ...F1(800Hz)  // 사람 '아' 소리의 특징 주파수
    const filter2 = ...F2(1200Hz)
    ...
  }
```
- **사람 목소리 "아~"를 흉내 낸** 소리. 톱니 파형을 두 개의 필터로 걸러 목소리처럼 만들어요.
- 진짜 목소리는 아니고 **근사치**(로봇 목소리 느낌)예요.

# 4. `src/training/StaircaseEngine.ts` — 난이도 계단 엔진

이 앱의 **심장부**. 정답/오답에 따라 난이도를 오르내립니다.

```ts
export interface StaircaseState {
  centsDifference: number;  // 지금 두 소리의 차이(작을수록 어려움)
  streak: number;           // 연속 정답 수(화면 표시용)
  isHigher: boolean;        // 이번 문제에서 B가 더 높은가?
  totalTrials: number;      // 총 푼 문제 수
  reversalCount: number;    // 난이도 방향이 바뀐 횟수
  ...
}
```
- `interface` = "이 데이터는 이런 모양이다"라고 그려둔 **설계도**. 실제 값이 아니라 형태 정의.

```ts
  prepareRound(): StaircaseState {
    const isHigher = Math.random() > 0.5;   // 동전 던지기로 B 방향 결정
    const centsOffset = isHigher
      ? this.state.centsDifference
      : -this.state.centsDifference;
    const rawTarget = centsToFreq(this.state.baseFreq, centsOffset);
    const { clamped: targetFreq } = clampFreq(rawTarget);  // 안전 범위로 자름
    this.state = { ...this.state, isHigher, targetFreq };
    return this.getState();
  }
```
- **새 문제를 준비**하는 함수.
- `Math.random() > 0.5` : 50% 확률로 B를 위/아래로 결정 (찍기 방지).
- 결정된 방향으로 목표 주파수를 계산하고, 안전 범위로 자른 뒤 상태에 저장.

```ts
  submitAnswer(userThinksHigher: boolean): TrialResult {
    const prev = this.state;
    const isCorrect = userThinksHigher === prev.isHigher;  // 정답 판정
```
- 사용자의 답과 실제 방향이 같으면 정답.

```ts
    if (isCorrect) {
      const counter = prev.stepCounter + 1;
      if (counter >= STAIRCASE.STREAK_THRESHOLD) {  // 2번 연속 정답이면
        nextCents = Math.max(MIN_CENTS, prev.centsDifference - step); // 차이를 줄임(어렵게)
      }
    } else {
      nextCents = Math.min(MAX_CENTS, prev.centsDifference + step);   // 틀리면 차이를 늘림(쉽게)
    }
```
- **2-down-1-up 규칙**: 2번 맞히면 한 단계 어렵게, 1번 틀리면 한 단계 쉽게.
- `Math.max(MIN_CENTS, ...)` : 아무리 줄여도 최소값 아래로는 안 내려가게.
- `Math.min(MAX_CENTS, ...)` : 아무리 늘려도 최대값 위로는 안 올라가게.

```ts
    if (nextCents !== prev.centsDifference) {
      const direction = nextCents < prev.centsDifference ? 'down' : 'up';
      if (this.lastDirection !== null && direction !== this.lastDirection) {
        this.reversals.push(prev.centsDifference);  // ★ 방향 바뀐 지점 기록 = '반전'
      }
      this.lastDirection = direction;
    }
```
- **"반전(reversal)" 감지**. 난이도가 내려가다가 올라가거나 그 반대로 **방향이 꺾인 지점**을 기록.
- 이 반전 지점들이 "내 실력 근처"라서, 나중에 이걸 평균 내면 점수가 됩니다.

```ts
  getThreshold(): number | null {
    if (this.reversals.length < THRESHOLD_MIN_REVERSALS) return null; // 반전 부족하면 점수 없음
    let used = this.reversals.slice(THRESHOLD_DISCARD_REVERSALS);     // 초반 2개는 버림
    if (used.length % 2 === 1) used = used.slice(1);                  // 짝수 개만 사용
    const mean = used.reduce((a, b) => a + b, 0) / used.length;       // 평균
    return Math.round(mean * 10) / 10;
  }
```
- **변별 역치(대표 점수) 계산**.
- 초반 반전은 아직 실력이 안 잡힌 구간이라 **버리고**, 위/아래 균형을 위해 **짝수 개**만 평균.
- 반전이 4번도 안 됐으면 `null`(점수 없음).

# 5. `src/training/SessionManager.ts` — 한 판(세션) 매니저 (지금 열려있는 파일)

난이도 엔진을 감싸서 **한 번의 훈련 전체**를 관리합니다.

```ts
  startSession(): void {
    this.startedAt = Date.now();   // 시작 시각 기록
    this.trials = [];              // 문제 기록 초기화
    this.isActive = true;
    this.staircaseEngine.reset(this.config.baseFreq);  // 난이도 엔진 리셋
  }
```
- **세션 시작**. 기록을 비우고 난이도 엔진을 처음 상태로 되돌림.

```ts
  openResponseWindow(): void {
    this.responseWindowOpenedAt = Date.now();
  }
```
- **"이제 답변받기 시작"** 시각을 찍음. 소리가 다 끝난 시점이에요.
- 반응 시간을 **소리 끝난 뒤부터** 재기 위한 장치. (소리 듣는 1.5초는 반응시간에 안 넣음)

```ts
  submitAnswer(userThinksHigher: boolean): TrialResult {
    const now = Date.now();
    const reactionTimeMs =
      this.responseWindowOpenedAt > 0 ? now - this.responseWindowOpenedAt : 0;
    const currentState = this.staircaseEngine.getState();
    const result = this.staircaseEngine.submitAnswer(userThinksHigher);

    this.trials.push({
      trialNumber: this.trials.length + 1,
      isCorrect: result.isCorrect,
      reactionTimeMs,        // 반응 시간
      replayCount: this.replayCount,  // 다시 듣기 누른 횟수
      centsDifference: currentState.centsDifference,
      isHigher: currentState.isHigher,
      timestamp: now,
    });
    ...
  }
```
- **답변 처리 + 기록**.
- `now - responseWindowOpenedAt` : "답변 가능해진 순간부터 실제 누른 순간까지" = 순수 반응 시간.
- 난이도 엔진에 답을 넘겨 판정받고, 그 결과를 `trials`(문제별 기록 목록)에 하나 추가.

```ts
  abortRound(): void {
    this.responseWindowOpenedAt = 0;
    this.replayCount = 0;
  }
```
- **문제 취소**. 전화가 오거나 앱을 나갔다 오면 소리를 놓친 거라, 그 문제를 **기록 없이 버림**.

```ts
  shouldAutoEnd(): boolean {
    if (this.config.mode !== 'assessment') return false;  // 훈련 모드는 안 끝남
    const state = this.staircaseEngine.getState();
    return state.reversalCount >= ASSESSMENT.TARGET_REVERSALS
        || state.totalTrials >= ASSESSMENT.MAX_TRIALS;
  }
```
- **평가 모드 자동 종료 판단**. 반전 8번 or 30문제에 도달하면 끝.
- 훈련 모드는 항상 `false` → 사용자가 원할 때까지 계속.

```ts
  endSession(): SessionResult {
    this.isActive = false;
    const state = this.staircaseEngine.getState();
    return {
      id: `session_${this.startedAt}`,
      thresholdCents: this.staircaseEngine.getThreshold(),  // 대표 점수
      reversals: [...this.staircaseEngine.getReversals()],
      trials: [...this.trials],
      ...
    };
  }
```
- **세션 종료**. 지금까지 모은 모든 정보를 **하나의 결과 꾸러미**로 만들어 반환.
- 이 꾸러미가 저장소로 가서 성적표·통계에 쓰여요.

# 6. `src/training/trainingFlow.ts` — 게임 규칙표 (공정성 담당)

화면에서 규칙만 떼어낸 **순수 함수**(입력→출력만 있고 부작용 없음) 모음.

```ts
export type GameState = 'idle' | 'playing' | 'waiting' | 'answered' | 'interrupted';
```
- 훈련 화면이 가질 수 있는 **5가지 상태**.
  - `idle`(대기) → `playing`(재생중) → `waiting`(답변 기다림) → `answered`(답함)
  - `interrupted`(앱 이탈로 중단됨)

```ts
export function canSubmitAnswer(state: GameState): boolean {
  return state === 'waiting';
}
```
- **"지금 답변받아도 되나?"** → `waiting`일 때만 된다.
- `answered`에서도 받으면 **정답 본 뒤 또 눌러서 점수 조작** 가능 → 그래서 딱 막음.

```ts
export function isReplayPress(state: GameState): boolean {
  return state === 'waiting';
}
```
- **재생 버튼이 '다시 듣기'로 동작할지** 판단. `waiting`이면 같은 문제 다시 듣기, 아니면 새 문제.

```ts
export function shouldAbortOnInterrupt(state: GameState): boolean {
  return state === 'playing' || state === 'waiting';
}
```
- **앱을 나갔을 때 문제를 버려야 하나?** 재생중이거나 답변 대기중이면 소리를 놓친 거라 버림.

```ts
export function showsTrialFeedback(mode: SessionMode): boolean {
  return mode === 'training';
}
```
- **문제마다 정답을 알려줄까?** 훈련은 O(배우려고), 평가는 X(중간에 요령 배우면 측정 왜곡).

# 9. `src/utils/haptics.ts` — 진동 도구

```ts
let enabled = true;

export function setHapticsEnabled(value: boolean): void {
  enabled = value;
}
```
- `enabled` = 진동 on/off 스위치. 파일 안에 하나만 두고 공유.

```ts
function safe(run: () => Promise<unknown>): void {
  if (!enabled) return;         // 꺼져 있으면 아무것도 안 함
  run().catch(() => {});        // 실패해도 조용히 무시
}
```
- **안전 실행기**. 진동 안 되는 폰에서도 앱이 안 멈추게, 오류를 삼켜버림.

```ts
export function hapticSuccess(): void {
  safe(() => Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success));
}
```
- 정답 진동, 오답 진동(`hapticError`), 가벼운 탭 진동(`hapticTap`)이 각각 있어요.
- 소리를 잘 못 듣는 사용자를 위한 **또 하나의 피드백 통로**.
