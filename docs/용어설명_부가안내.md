# 용어 부가 안내 (짧은 `역치` ↔ 긴 말)

## 목적

좁은 UI에는 `역치`를 유지하고, 사용자가 헷갈릴 수 있는 자리에서만 긴 설명으로 이어 준다.

## 적용

| 위치 | 방식 | 내용 |
|------|------|------|
| 훈련 진행 문구 (훈련 모드) | 탭 → Alert | `THRESHOLD_TERM_HELP` |
| 통계 `최고 역치` 타일 | 탭 → Alert | 동일 |
| 결과 히어로 `—` | 상시 한 줄 | 세션 저장됨 / 최소 차이 미계산 |
| 통계 차트 빈 상태 | 문구 구체화 | 최소 차이가 나온 세션 2회 이상 |

공유 문구: `src/constants/theme.ts` → `THRESHOLD_TERM_HELP`
