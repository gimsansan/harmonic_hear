# 하모니튠(HarmoniTune) 앱 구조 — 초보자용 쉬운 해설

> 이 문서는 코딩을 처음 접하는 분도 "이 앱이 어떻게 굴러가는지" 이해할 수 있도록
> 실생활 비유를 곁들여 쉽게 풀어 쓴 해설입니다.
> (대상 범위: `app/`, `src/` 폴더 — `node_modules`, `reports`, `files`, `docs`, `assets` 제외)

---

## 0. 이 앱은 뭘 하는 앱인가요?

**두 소리(A, B)를 듣고 "B가 A보다 높나요, 낮나요?"를 맞히는 청각 훈련 앱**이에요.
맞힐수록 두 소리의 차이가 점점 작아져서 더 어려워지고, 틀리면 다시 쉬워집니다.
마치 시력검사표에서 글씨가 점점 작아지는 것처럼, **"내 귀가 얼마나 미세한 차이까지 구별하는지"** 를 재는 앱입니다.

---

## 1. 큰 그림: 식당으로 비유하기

앱을 **식당**이라고 생각해 볼게요.

| 앱의 구성 | 식당 비유 | 하는 일 |
|-----------|-----------|---------|
| `app/` (화면) | **홀 (손님이 앉는 자리)** | 손님(사용자)이 보고 만지는 공간 |
| `src/` (로직) | **주방 (요리하는 곳)** | 실제로 소리를 만들고 계산하는 곳 |

손님은 주방이 어떻게 요리하는지 몰라도 됩니다. 그냥 홀에서 주문하고 음식을 받으면 되죠.
마찬가지로 **화면(`app`)은 "보여주기"만 하고, 진짜 일(소리 합성·난이도 계산·기록 저장)은 주방(`src`)이 다 합니다.**

---

## 2. 손님이 걷는 길 (화면 이동 순서)

```
홈 → (처음이면) 볼륨 맞추기 안내 → 훈련 → 결과 → 통계 / 설정
```

1. **홈**에서 "훈련 시작"을 누르면
2. 앱을 처음 켰다면 **볼륨 맞추기 안내**가 먼저 나오고
3. 본격 **훈련**을 하고
4. 끝나면 **결과**를 보고
5. **통계**나 **설정**으로 갈 수 있어요.

---

## 3. `app/` 폴더 — 손님이 보는 화면들

이 폴더는 **파일 하나가 화면 하나**예요. 쉽죠?

| 파일 | 어떤 화면? | 쉬운 설명 |
|------|-----------|-----------|
| `_layout.tsx` | 공통 뼈대 | 모든 화면에 공통으로 적용되는 **액자 틀**. 배경색, 화면 넘김 효과 담당 |
| `index.tsx` | 홈 | 앱을 켜면 처음 보이는 **현관**. 훈련·통계·설정으로 가는 문 |
| `onboarding.tsx` | 볼륨 맞추기 | "소리부터 편하게 맞추세요"라고 알려주는 **첫 안내원**. 딱 한 번만 등장 |
| `training.tsx` | 훈련 | 앱의 **메인 무대**. 소리 A→B를 들려주고 답을 받는 가장 중요한 화면 |
| `result.tsx` | 결과 | 훈련이 끝난 뒤 보는 **성적표** |
| `stats.tsx` | 통계 | 그동안의 기록을 모은 **성장 일기장** |
| `settings.tsx` | 설정 | 기준음·진동 등을 바꾸는 **환경설정 방** |

> 💡 **왜 `training.tsx`가 제일 클까요?**
> 소리를 순서대로 들려주고, 답을 받고, 앱을 나갔다 오면 그 문제를 취소하고, 기록을 저장하는 등
> **"진행을 지휘하는" 지휘자 역할**이라 코드가 가장 많아요.

---

## 4. `src/` 폴더 — 주방(진짜 일하는 곳)

주방은 역할별로 방이 나뉘어 있어요.

### 📦 `src/constants/` — 규칙이 적힌 수첩
- **`theme.ts`** : 색깔, 글자 크기, 소리 길이, 난이도 규칙 등 **앱의 모든 숫자·설정이 적힌 수첩**.
  요리로 치면 **레시피 노트**예요. 여기 숫자만 바꾸면 앱 전체 맛(동작)이 바뀝니다.

### 🔊 `src/audio/` — 소리를 만드는 방
- **`AudioEngine.ts`** : 실제로 "삐~" 소리를 만드는 **신디사이저(전자 악기)**.
  중요한 점 하나! A와 B 소리를 **미리 한꺼번에 예약**해서 틀어요.
  → 왜냐하면 폰이 잠깐 버벅여도 A와 B 사이 간격이 흔들리면 안 되거든요.
  (간격이 들쭉날쭉하면 사용자가 소리 높낮이가 아니라 "타이밍"으로 눈치채버려요.)
- **`pitchUtils.ts`** : 소리 계산을 도와주는 **계산기**. "이 음보다 조금 높은 음은 몇 Hz?" 같은 걸 계산.
- **`__tests__/`** : 위 계산기와 신디사이저가 **고장 안 났는지 자동으로 확인하는 검사기**.

### 🎯 `src/training/` — 훈련 규칙을 담당하는 방 (가장 핵심!)
- **`StaircaseEngine.ts`** : **난이도 조절 장치(계단 오르내리기)**.
  - 2번 연속 맞히면 → 한 계단 어렵게 (소리 차이를 줄임)
  - 틀리면 → 한 계단 쉽게 (소리 차이를 늘림)
  - 이렇게 오르락내리락하다 보면 **"내 진짜 실력 지점"** 에서 왔다갔다 하게 되고,
    그 지점들의 평균이 바로 이 앱의 대표 점수인 **변별 역치**예요.
- **`SessionManager.ts`** : **한 판(세션)의 진행 매니저**.
  난이도 장치를 감싸서 "지금 몇 문제째인지, 반응 속도는 얼마인지, 다시 듣기를 몇 번 눌렀는지"를 챙기는 **비서**.
- **`trainingFlow.ts`** : **게임 규칙표(순수 함수 모음)**.
  "답은 한 문제에 딱 한 번만 받는다", "재생 중엔 버튼 못 누른다" 같은 **공정성 규칙**을 모아둔 곳.
  → 규칙을 화면에서 분리해두면, 규칙만 따로 테스트하고 관리하기 쉬워요.
- **`__tests__/`** : 위 세 규칙 파일이 **나중에 실수로 망가지지 않게 잠가두는 자물쇠(테스트)**.

> 💡 **이 폴더가 왜 복잡해 보일까요?**
> 이 앱은 "측정"이 핵심이라, 규칙이 조금만 틀어져도 점수가 엉터리가 돼요.
> 그래서 규칙마다 **파일을 잘게 나누고 + 테스트로 이중 확인**하다 보니 파일이 많아 보이는 거예요.
> 복잡한 게 아니라 **꼼꼼한** 겁니다. 😊

### 🧩 `src/components/` — 재사용하는 화면 부품
레고 블록처럼, 여러 화면에서 가져다 쓰는 **UI 조각**들이에요.

| 파일 | 무슨 부품? |
|------|-----------|
| `ModeTab.tsx` | 순수 파형 / 사람 목소리 **모드 선택 탭** |
| `AnswerButtons.tsx` | "B가 높음 / 낮음" **답변 버튼** |
| `SkiaWaveVisualizer.tsx` | 소리를 그림으로 보여주는 **파형 애니메이션** |
| `FeedbackCard.tsx` | 정답/오답을 알려주는 **피드백 카드** |
| `ThresholdChart.tsx` | 통계 화면의 **성장 그래프** |

### 💾 `src/storage/` — 기록을 보관하는 창고
- **`TrainingStorage.ts`** : 훈련 결과를 폰 안에 저장하는 **기록 창고**. (인터넷 없이 폰에만 저장)
- **`AppSettingsStorage.ts`** : 기준음·진동 같은 **설정만 따로 보관하는 서랍**.

### 🛠 `src/utils/` — 편의 도구함
- **`haptics.ts`** : 정답/오답을 **진동으로 알려주는 도구**.
  소리를 잘 못 듣는 분들을 위해 진동으로도 알려줘요. 설정에서 끌 수 있어요.

---

## 5. 실제 한 문제가 도는 과정 (전체 흐름 총정리)

1. 사용자가 **재생 버튼**을 누른다 → (`training.tsx`)
2. 매니저가 **새 문제를 준비**한다 (B가 높을지 낮을지 랜덤 결정) → (`SessionManager` + `StaircaseEngine`)
3. 신디사이저가 **소리 A → 잠깐 쉬고 → 소리 B**를 틀어준다 → (`AudioEngine`)
4. 소리가 끝나면 **답변 버튼**이 켜진다 → (`AnswerButtons`)
5. 사용자가 "높음/낮음"을 누르면 **정답 판정 + 난이도 조절** → (`StaircaseEngine`)
6. 진동과 피드백 카드로 결과를 알려준다 → (`haptics`, `FeedbackCard`)
7. 세션을 끝내면 결과를 **창고에 저장**하고 **성적표 화면**으로 이동 → (`TrainingStorage`, `result.tsx`)

---

## 6. 딱 한 줄 요약

> **`app` = 보여주는 홀, `src` = 요리하는 주방.**
> 그중 `src/training`이 이 앱의 **두뇌**, `theme.ts`가 모든 규칙을 조절하는 **다이얼**입니다.
